# Nova 상품 운영 어드민

React 없이 HTML, TypeScript, Tailwind CSS v4로 구성한 Vite SPA입니다.

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 Vite가 출력한 로컬 주소를 엽니다. 기본 주소는 `http://localhost:5173`입니다.

## 빌드

```powershell
npm run build
npm run preview
```

원본 단일 파일은 `product-admin-prototype-simple.html`로 보존되어 있습니다.
