기준

운영자가 만드는 것은 상품전시 하나다. 상품 구성과 전시 설정을 한 화면에서 끝내고, 단품은 EPC에서 오는 재료로 쓴다.

상품전시 구성

섹션정하는 것PO
1. 상품전시 정보전시명, 전시유형, 채널, 카테고리, 기간, 노출 여부. 전시유형이 섹션 2의 선택 범위를 정한다해당 없음
2. 기준 단품전시유형에 맞는 단품 1개. 디바이스형은 모델을 고르면 그 모델이 가진 옵션값(색상, 용량 등)을 골라 옵션목록을 만들고, 가입유형·할인방법을 여기서 정한다1 (패스형 구독은 0 가능)
3~. 슬롯0~N개. 버튼으로 추가·삭제. 슬롯마다 제공 방식(고객 선택 / 전체 제공), 필수/선택, 영역, 상품유형, 최대 선택 수, 후보 목록을 정한다. 전체 제공은 고른 상품 전부가 자동 포함된다필수 슬롯 수 + 전체 제공 상품 수 ~ 최대 선택 수 합계
대표 슬롯, 추가 슬롯이라는 구분은 없앴다. 섹션 2는 "무엇을 파는 전시인가"를 정하는 자리이고, 나머지는 전부 같은 규칙의 슬롯이다. 슬롯이 0개인 상품전시가 예전의 단품 판매다.
